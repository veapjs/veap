# @veap/core v0.1.0

The core framework of the Veap ecosystem: a headless modular application container and runtime.

## Concept & Architecture
- **Dependency Container & Config**: Type-safe configuration loader with Zod schemas.
- **Logging**: Structured logger built on Pino.
- **Error Hierarchy**: Domain-driven exception classes with HTTP status codes.

Bootstraps headlessly as an importable library.
